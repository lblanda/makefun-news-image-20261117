One image summing up the world news of Tuesday 17 November 2026, written
for the make.fun news-image-20261117 bounty: an editorial news poster
drawn entirely in code.

`main.py` is the whole entry: a pure Python 3 standard-library program
(no third-party packages, no network at run time) that draws a 1024x1024
news poster — masthead, lead story, six captioned story panels, a
ticker of the day's other news — and writes it to `entry.png`. It embeds
its own 5x7 bitmap font and a hand-rolled PNG encoder, so the program is
fully deterministic: two runs write byte-identical files.

The day it sums up: the US strikes on Iran and Tehran's reply in the Gulf,
Ukraine hitting the Kerch Bridge again, Trump at the Quad in Manila, the
stock slide into correction, Nvidia's record $115bn quarter with no CEO
comeback, the Optimizely cyberattack on 178 top sites, COP31's fossil-fuel
exit draft, and more in the ticker.
